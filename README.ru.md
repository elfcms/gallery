# Gallery Module for ELF CMS

Модуль для отображения галерей изображений. Идеально подходит для сайтов художников, фотографов и портфолио.

## 🚀 Возможности

- Загрузка изображений и организация в альбомы
- Гибкая настройка отображения галерей
- Поддержка подписей, категорий и тегов

## 📦 Установка

```bash
composer require elfcms/gallery
```

## ⚙️ Использование

Документация по использованию модуля находится в папке `docs` или будет добавлена позже.

## 🧩 Требования

- Laravel >= 10.0
- PHP >= 8.1

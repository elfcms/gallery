# Gallery Module for ELF CMS

Module for displaying image galleries. Perfect for artist, photography, or portfolio websites.

## 🚀 Features

- Upload images and organize them in albums
- Flexible gallery display configuration
- Captions, categories, and tags support

## 📦 Installation

```bash
composer require elfcms/gallery
```

## ⚙️ Usage

Documentation will be added later in the `docs` folder.

## 🧩 Requirements

- Laravel >= 10.0
- PHP >= 8.1

# Galerie Modul for ELF CMS

Modul zur Anzeige von Bildergalerien. Ideal für Websites von Künstlern, Fotografen oder Portfolios.

## 🚀 Funktionen

- Bilder hochladen und in Alben organisieren
- Flexible Galerieanzeige-Konfiguration
- Unterstützung von Bildunterschriften, Kategorien und Tags

## 📦 Installation

```bash
composer require elfcms/gallery
```

## ⚙️ Verwendung

Documentation will be added later in the `docs` folder.

## 🧩 Anforderungen

- Laravel >= 10.0
- PHP >= 8.1
